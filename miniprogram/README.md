# 成语接龙 · 微信小程序壳

本目录是一个**微信小程序原生壳**，通过 `<web-view>` 组件内嵌已部署的 H5 站点
（`https://yzbb1991.github.io/chengyu-chain/`），从而实现「同一个 H5 应用，既能在手机浏览器打开，也能在微信小程序里运行」。

游戏逻辑与界面全部在 H5 侧（仓库根目录的 `src/`），小程序侧只负责承载与转发/分享。
H5 仍是单一代码源，无需为小程序重写一遍界面。

## 目录结构
```
miniprogram/
├── project.config.json   # 小程序项目配置（appid 已填 wx4bd237a397a073bb）
├── app.json              # 全局配置（页面注册、导航栏样式）

├── app.wxss

```

## 在微信开发者工具里预览
1. 下载并打开「微信开发者工具」。
2. 选择「导入项目」→ 目录选择本仓库根目录（开发者工具会自动识别 `miniprogram/` 下的 `project.config.json`；若未自动识别，目录请直接选 `miniprogram/`）。
3. AppID 已预填为 `wx4bd237a397a073bb`（如提示无权限，可在工具里改用「测试号」预览）。
4. 导入后默认**勾选「不校验合法域名…」**（本项目 `project.config.json` 已设 `urlCheck:false`），即可直接看到 H5 游戏运行在小程序内。

## 真机调试 / 转发分享
- 小程序页面已配置 `onShareAppMessage` / `onShareTimeline`，可在小程序内把游戏转发给好友或分享到朋友圈（分享的是小程序本身，进入即加载 H5）。
- 如需从 H5 内部直接调起小程序分享卡片，web-view 内的 H5 受限较多，当前采用「分享小程序」方案即可满足。

## 生产发布的关键限制（重要）
微信小程序 `<web-view>` 加载的域名必须：
1. 是 **HTTPS**；
2. 在微信公众平台 →「开发管理 → 开发设置 → 业务域名」中**添加并校验**（需下载校验文件放到域名根目录）；
3. 通常要求域名已完成 **ICP 备案**，且备案主体与你小程序账号一致。

本项目线上地址是 `yzbb1991.github.io`（GitHub Pages）。**github.io 不是你自己的备案域名**，因此：
- ✅ 开发预览 / 真机调试（开发者工具勾选不校验域名）：立即可用；
- ⚠️ 正式提交审核上架：大概率因业务域名备案问题被拒。

### 上架生产的两个可行路径
- **A. 绑定你自己的已备案域名**：把你的域名（如 `game.yourdomain.com`）CNAME 指向 GitHub Pages（或部署到该域名），然后在微信后台把该域名加为业务域名、上传校验文件。校验文件放仓库根目录后由我重新部署 `gh-pages` 即可。改 `app.js` 里的 `h5Url` 指向你的域名。
- **B. 真原生重写（无域名限制）**：把 `src/` 的界面层改写为小程序原生组件（游戏逻辑 `src/game/*` 可复用），彻底去掉 web-view，这样无需任何业务域名即可上架。工作量较大，需要我另开一轮实现。

> 如果你希望走路径 B，或已有备案域名要走路径 A，告诉我即可。
